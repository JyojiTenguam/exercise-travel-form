# 🌍 Travel Form

Exercício focado na construção de um formulário interativo com validações utilizando JavaScript, com o objetivo de aplicar os conceitos aprendidos sobre manipulação de DOM e eventos.

## ✨ Demonstração

> Este projeto simula um formulário de viagem, onde o usuário preenche suas informações e recebe feedback dinâmico em tempo real.

## 💡 Sobre

O objetivo deste exercício é construir um formulário de viagem, permitindo que o usuário preencha seus dados e, em seguida, valide as informações inseridas. Além disso, o formulário interage com o usuário por meio de mensagens dinâmicas utilizando JavaScript.

## 🛠️ Habilidades desenvolvidas

- Manipulação de eventos com JavaScript
- Validação de dados em formulários
- Manipulação do DOM para exibição de mensagens dinâmicas
- Aplicação de lógica condicional e de controle

## 🧪 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript ES6+
